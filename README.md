# FOR NEM Catering Co.

Landing page for **FOR NEM Catering Co.** — Chicago's hoodest, ghettoest catering company. Full-service catering for weddings, cookouts & block parties, corporate events, repasts, and bar service. South Side (Englewood), serving all of Chicago and the suburbs.

> If foe nem eatin', everybody eatin'.

## Structure

- `index.html` — the landing page (single file, styles inline). Lives on the `feature/catering-landing-page` branch.
- `logo.svg` — the FN badge logo (also used as the site favicon).

## Live

- Deployed on forge2: http://198.23.150.34/for-nem/ (the earlier `/maison-verde/` path redirects here)

## Notes

- The inquiry form is functional client-side: on submit it opens the visitor's email app with the inquiry pre-addressed and filled in (mailto). There is no server backend.
- Contact details, packages, and prices on the page are the company's real published details as of Nov 19, 2026.
